# קשת הסולמות

אפליקציית ווב ללימוד סולמות ובניית שמיעה: מטרונום, צבעים וקול ששר את שמות הצלילים.

```bash
npm install
npm run dev      # פיתוח
npm test         # בדיקות
npm run build    # בנייה ל-dist, כולל PWA
```

- הוספת סולם: שורה אחת ב-`src/music/scales.data.ts`.
- הקלטת קולות אמיתיים: `docs/recording-guide.md`.
- מיקרופון והתקנה בטלפון דורשים https.
