# הקלטת הקולות

האפליקציה עובדת גם בלי הקלטות, על קול מסונתז. קול עובר להקלטות רק כשיש לו את כל 11 ההברות.

## מה מקליטים
- **הברות (11):** do, re, mi, fa, sol, la, si, di, ez, be, mol
- **גבהים (כל 3 חצאי טון):**
  - גבר (`male`): 45, 48, 51, 54, 57, 60, 63, 66, 69 (A2 עד A4)
  - אישה (`female`): 57, 60, 63, 66, 69, 72, 75, 78, 81 (A3 עד A5)
- סך הכל 99 קבצים לכל קול.

## איך מקליטים
1. חדר שקט, מיקרופון במרחק 15–20 ס"מ, אותה עוצמה ואותו מרחק לאורך כל הסשן.
2. שמע את הצליל מטיונר או פסנתר באוזניות, ושיר הברה אחת קצרה, כחצי שנייה, בלי ויברטו.
3. השאר חצי שנייה של שקט לפני ואחרי. הסקריפט יחתוך אותו.
4. שמור כל הברה בקובץ נפרד בשם `{syllable}_{midi}.wav`, למשל `sol_60.wav`.

```
raw/
  female/do_57.wav
  female/do_60.wav
  male/do_45.wav
```

## עיבוד
צריך את ffmpeg (`brew install ffmpeg`):

```bash
npm run voices -- raw
```

הסקריפט חותך שקט, מנרמל עוצמה, מייצא ל-`public/voices/{female|male}/{syllable}_{midi}.mp3`, בונה את `public/voices/manifest.json`, ומדווח אילו הברות חסרות.
